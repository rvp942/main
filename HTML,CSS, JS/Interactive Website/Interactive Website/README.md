
# Interactive Website

This is a simple interactive website that allows users to change the background color by clicking a button. The project demonstrates the use of HTML, CSS, and JavaScript to create an interactive experience.

## Features

- A button that changes the background color of the webpage to a randomly generated color.
- Smooth transition effect for the background color.
- Clean and modern design with a centered content container.

## Project Structure

- **index.html**: The main HTML file containing the structure of the webpage.
- **style.css**: The CSS file responsible for styling the webpage.
- **script.js**: The JavaScript file implementing the background color change functionality.

## How to Use

1. Download or clone the repository.
2. Open the `index.html` file in any modern web browser.
3. Click the "Change Background Color" button to see the magic.

## Installation

No installation is required. Simply open the `index.html` file in your browser to use the website.
